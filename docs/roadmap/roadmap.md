## ISOM-00 Основа проєкту — контрольний перелік

Виконано у Foundation v0.1 (лише документація):

- [x] Структура документації та правила оформлення ([README.md](../../README.md))
- [x] Контекст системи, архітектурні принципи, архітектурні рішення, шари, структура модулів
- [x] Концептуальна доменна модель, автомат станів майна, життєвий цикл документа
- [x] Архітектура безпеки
- [x] Робоча модель класифікації даних
- [x] Початкові функціональні та нефункціональні вимоги
- [x] Каталог бізнес-правил
- [x] Реєстр нормативних джерел (записи не пройшли юридичної перевірки)
- [x] Матриця відповідності (структура трасування; усі рядки «Заплановано» / «Буде визначено»)
- [x] Каталог вимог безпеки
- [x] Модель зберігання документів
- [x] Процеси: надходження, передача, інвентаризація, ремонт, списання
- [x] Каталог сутностей, довідники, модель аудиту
- [x] Дорожня карта
- [x] Розділ про майбутнє технічне завдання та журнал конфліктів
- [x] Переклад документації українською мовою

Залишилося для ISOM-00:

- [ ] Розгляд і затвердження Foundation v0.1 замовником
- [ ] Юридична перевірка реєстру нормативних джерел (LEG-01 … LEG-21)
- [ ] Надання внутрішніх документів (LEG-22) належним каналом
- [ ] Надання технічного завдання (LEG-23) і його зіставлення з цією документацією
- [ ] Вирішення відкритих питань (`OQ-*`), що блокують ISOM-01 … ISOM-05
- [ ] Рішення щодо технологічного стеку (свідомо відкладено, AD-13)
- [x] Інструкції для учасників / агентів на рівні репозиторію ([AGENTS.md](../../AGENTS.md))
