# Каталог сутностей

**Статус:** Чернетка · **Версія:** 0.1 · **Оновлено:** 2026-10-02

Це концептуальний каталог, а **не** схема бази даних. Міграцій немає. Зв'язки показано на діаграмі в [domain-model.md](../architecture/domain-model.md). Робочі класи (`DC-*`) посилаються на [data-classification.md](../architecture/data-classification.md) і не є остаточними. Назви сутностей наведено англійською, бо вони стануть ідентифікаторами в коді.

Спільні атрибути всіх бізнес-сутностей нижче не повторюються:

- ID;
- `createdAt`, `createdBy`, `updatedAt`, `updatedBy`;
- `recordState`: Active, Cancelled, Superseded, Invalidated або Archived (BR-05).

## 1. Організація та розташування

| Сутність | Відповідальність | Ключові атрибути |
|---|---|---|
| Organization | Юридична особа / балансоутримувач | Назва, код ЄДРПОУ, статус |
| StructuralUnit | Структурний підрозділ (ієрархічний) | Назва, код, батьківський підрозділ, організація, строк дії |
| Location | Абстрактний вузол фізичного розташування | Тип, батьківський вузол, строк дії, клас |
| Site | Територія / адреса | Назва, адреса (клас може бути підвищено) |
| Building | Будівля на території | Назва / номер |
| Floor | Поверх будівлі | Номер / позначка |
| Room | Приміщення на поверсі | Номер / позначка, призначення |
| Warehouse | Обліковий склад | Назва, код, підрозділ, що його експлуатує, завідувач(і) складу |
| StorageLocation | Найнижчий рівень зберігання (стелаж, шафа, зона) | Код, приміщення, склад |

## 2. Майно

### Asset

Єдиний центральний запис для кожної одиниці майна (AP-01).

| Атрибут | Примітки | Робочий клас |
|---|---|---|
| Asset ID | Внутрішній ідентифікатор, не розміщується на мітках | DC-2 |
| Інвентарний номер | Унікальний у визначених межах (OQ-14) | DC-2 |
| Номенклатурний номер | Де застосовно | DC-2 |
| Категорія майна | → AssetCategory | DC-2 |
| Тип майна | → AssetType | DC-2 |
| Назва, опис | — | DC-2 (може бути підвищено для категорії) |
| Виробник, модель, заводський номер, рік виготовлення | — | DC-2 (може бути підвищено для категорії) |
| Одиниця виміру, кількість | — | DC-2 |
| Первісна вартість, залишкова вартість | Поточні значення. Історія — в AssetValuation. | DC-4 |
| Дата введення в експлуатацію, строк корисного використання | — | DC-4 |
| Джерело фінансування, рахунок обліку | Довідники | DC-4 |
| Статус | → AssetStatus. Змінюється лише операціями (AD-01). | DC-2 |
| Технічний стан | → AssetCondition | DC-2 |
| Організація, структурний підрозділ | Поточні | DC-2 |
| Місце зберігання | Поточне. Історія — в AssetLocationHistory. | DC-2 (підвищується для обмежених категорій) |
| Посилання на закріплення за МВО | → чинний CustodyAssignment. Ніколи не рядок із ПІБ (BR-11). | DC-2 (дані, на які посилається, — DC-3) |
| Документальна підстава | → документ, яким створено або востаннє змінено запис | DC-2 |
| Штрихкод, QR-код | → Barcode / QrCode (непрозорі) | DC-1 |
| Клас безпеки | Класифікація запису майна | DC-2 |
| Створено, оновлено | — | DC-2 |

### Інші сутності майна

| Сутність | Відповідальність |
|---|---|

| AssetType | Детальніша класифікація в межах категорії |

| AssetCondition | Контрольований перелік технічних станів |

## 3. Особи та закріплення

| Сутність | Відповідальність | Ключові атрибути | Робочий клас |
|---|---|---|---|
| Person | Фізична особа (мінімум даних, LEG-12) | ПІБ, статус | DC-3 |
| Employee | Трудові відносини | Person, табельний номер, посада, підрозділ, строк дії | DC-3 |
| ResponsiblePerson | Роль особи як матеріально відповідальної | Person, статус, початок/кінець відповідальності, документ-підстава, закріплені склади/розташування | DC-3 |
| CustodyAssignment | Історія закріплення майна | Майно, ResponsiblePerson, діє з/по, документ-підстава, операція відкриття/закриття | DC-2 / DC-3 |

## 4. Переміщення

| Сутність | Відповідальність |
|---|---|
| Transfer | Заголовок операції переміщення: вид (див. [transfer.md](../workflows/transfer.md)), сторони, документ-підстава, статус, очікувана дата повернення |
| TransferItem | Майно / кількість у передачі, результат приймання |
| AssetMovement | Факт проведеного переміщення (історія) |

| Сутність | Відповідальність |
|---|---|

## 6. Списання та обслуговування

| Сутність | Відповідальність |
|---|---|
| WriteOffCase | Заголовок справи: варіант процесу, етап, ініціатор, рішення |
| WriteOffCommission | Члени, голова, розпорядчий документ про створення |
| WriteOffItem | Майно / кількість у справі, результат щодо позиції |
| TechnicalAssessment | Оцінка комісією технічного стану позиції |
| RecoveredMaterial | Матеріал, отриманий після розбирання або утилізації. Стає новою обліковою одиницею (BR-18). |
| MaintenanceCase | Епізод обслуговування або ремонту |

## 7. Документи

| Сутність | Відповідальність |
|---|---|
| DocumentType | Налаштовуваний тип: версія шаблону, життєвий цикл, правила погодження, вимога підпису, категорія зберігання (AD-07) |
| Document | Номер, дата, тип, статус, автор, пов'язана операція, дані зберігання |
| DocumentApproval | Особа, що погоджує, рішення, час, коментар, крок погодження |
| DocumentSignature | Підписувач, вид підпису (у майбутньому КЕП), результат перевірки, час (AD-12) |
| Attachment | Метадані файлу, хеш, клас, зв'язок із документом або майном |

Типи документів-кандидати наведено в [reference-data.md](reference-data.md#типи-документів).

| Сутність | Відповідальність |
