# Довідники

**Статус:** Чернетка · **Версія:** 0.1 · **Оновлено:** 2026-10-02

Довідники — це конфігурація (AP-10). Кожен довідник:

- **версіонований**: значення мають строк дії, а історичні записи зберігають значення, що діяло на той момент;
- **аудитований**: зміни створюють події аудиту;
- **без руйнівних змін**: використані значення деактивуються, але ніколи не видаляються.

Наведені нижче значення є **кандидатами**. Остаточні значення визначаються перевіреними нормативними актами, замовником і технічним завданням.

## Типи документів

Це типи документів (DocumentType)-кандидати. Кожен налаштовується: версія шаблону, життєвий цикл, правила погодження, вимога підпису, категорія зберігання (AD-07). Типові форми не зашиваються в код.

| Тип документа | Типове призначення |
|---|---|
| Прибутковий документ (Receipt) | Надходження майна |
| Акт приймання (Acceptance Act) | Приймання майна |
| Акт приймання-передачі (Transfer Act) | Передача між сторонами |
| Акт внутрішнього переміщення (Internal Movement Act) | Переміщення в межах установи |
| Наказ про проведення інвентаризації (Inventory Order) | Підстава для кампанії інвентаризації |
| Інвентаризаційний опис (Inventory List) | Результати фізичної перевірки |
| Порівняльна відомість (Inventory Reconciliation) | Звіряння результатів і облікових даних |
| Заявка на списання (Write-off Request) | Ініціювання справи списання |
| Акт технічного стану (Technical Condition Act) | Технічна оцінка позиції |
| Протокол засідання комісії (Commission Protocol) | Фіксація рішення комісії |
| Акт списання (Write-off Act) | Облікова підстава для списання |
| Акт передачі в ремонт (Repair Transfer Act) | Передача в ремонт або на модернізацію |
| Акт приймання з ремонту (Repair Acceptance Act) | Повернення з ремонту |
| Складський документ (Warehouse Document) | Складські операції |
| Документ про призначення МВО (Responsible Person Assignment) | Підстава для закріплення |
| Інший супровідний документ (Other Supporting Document) | Будь-які інші підтвердні документи |

Відповідність цих типів конкретним типовим формам (LEG-06, LEG-07) очікує юридичної перевірки.
