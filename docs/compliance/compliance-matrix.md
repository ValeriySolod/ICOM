# Матриця відповідності

**Статус:** Чернетка · **Версія:** 0.1 · **Оновлено:** 2026-10-02

## 1. Модель трасування

```
Норма / вимога -> Бізнес-правило -> Модуль ISOM -> Реалізація -> Перевірка / тест
```

- **Норма / вимога:** запис `LEG-*` з [реєстру нормативних джерел](legislation-register.md). Згодом також пункти ТЗ (LEG-23) і вимоги `SEC-*`.
- **Бізнес-правило:** запис `BR-*` з [business-rules.md](../requirements/business-rules.md).
- **Модуль:** з [system-context.md](../architecture/system-context.md#8-структура-модулів).
- **Реалізація:** інкремент дорожньої карти, згодом — посилання на код.
  - Значення: `Заплановано (ISOM-nn)`, `У роботі`, `Реалізовано`.
- **Перевірка / тест:** посилання на тести.
  - Значення: `Буде визначено`, `Визначено`, `Проходить`, `Перевірено рецензуванням`.

Кожен рядок, що спирається на нормативний акт, залежить від юридичної перевірки відповідного джерела `LEG-*`. У межах ISOM-00 жоден рядок не реалізовано й не перевірено.

## 3. Супровід

- Додавайте рядок щоразу, коли з'являється нове правило `BR-*`, вимога `SEC-*` або вимога ТЗ.
- Коли змінюється редакція джерела `LEG-*`, переглядайте всі рядки, що на нього посилаються.
- Комірка «Реалізація» отримує значення `Реалізовано` лише з посиланням на код. Комірка «Перевірка / тест» отримує значення `Проходить` лише з посиланням на тест, який фактично запускався.
